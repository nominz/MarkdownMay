| 状态 | 含义 |

## 3. 本轮验收口径

- DEF-010：菜单窗口四角均被真实窗口区域裁剪，右下角不存在方形像素或阴影尖角。
- DEF-011：文件菜单打开时，鼠标横移到编辑、格式等顶层菜单，无需单击即可切换对应下拉菜单。
- DEF-012：输入 `* ` 和正文后回车，源码自动插入下一行 `* `，渲染区显示下一项目符号；空项目再次回车退出列表。
- DEF-013：输入 `1.` 时保持普通文本，输入空格后成为有序列表；输入正文并回车后源码自动生成 `2. `。
- DEF-014：允许同时运行多个独立顶层窗口，每个窗口拥有自己的单活动文档；双击或命令行打开新文件时新建窗口，不再转发给既有进程。该口径须先进入需求与设计评审。
- DEF-015：在任意两个块之间按 Enter 后，插入点停留在新建空行，后续输入落入该空行，不跳到下一段。
- DEF-016：在长文档中间输入 `* `、正文并按 Enter，必须在当前位置生成下一同级项目，不跳出列表或跳到其他段落。
- DEF-017：对照模式左栏按 Enter 后立即切回渲染模式，切换在可接受时间内完成，窗口保持响应，内容不丢失。
- DEF-018：严格复现“回车→`*`→空格→正文→回车续项→空项回车退出→输入 `1`”；单独 `1` 必须保持普通文本，只有完整合法有序列表前缀形成后才转换。
- DEF-019：约 15 KB 混合格式文档连续普通文字输入不得触发每键全量重投影，不得出现 1～4 秒冻结；结构语法形成时仍须即时更新所见即所得结果。
- DEF-020：渲染模式输入后进入对照模式，在左侧源码插入 `# 标题1`，确认右侧渲染更新后返回渲染模式；应在 1 秒内完成且内容正确、窗口保持响应。
- DEF-021：工具栏只显示清晰的 Fluent 图标；按钮悬停、按下和选中背景为小圆角矩形，中文命令说明保留在工具提示中。
- DEF-022：状态栏文字与分区边界之间保留 12 px（按 DPI 缩放）内边距，分隔线不顶满高度，整体保持 24 px 轻量高度。
- DEF-023：退出未保存文档时使用 Windows 现代任务对话框，显示“保存／不保存／取消”，按钮视觉由系统 Win11 主题提供圆角。
- DEF-024：Release EXE 必须在进入主窗口前不依赖不可用的 `comctl32` 序号；Windows 10/11 均应正常启动，现代任务对话框不可用时必须安全回退。
- DEF-025：工具栏段落样式必须使用不可自由输入的原生下拉列表，显示“正文、一级标题～六级标题”，选择后立即作用于当前块。
- DEF-026：粗体、斜体、删除线必须是可逆开关；光标或选区位于相应格式范围时，工具栏按钮必须显示选中状态。Markdown 基线未定义下划线命令，本项不新增 HTML 下划线扩展。
- DEF-027：行内代码按钮必须以清晰的 `</>` 语义图形显示。
- DEF-028：鼠标停留于后台窗口工具栏按钮时，无需先激活主窗口即可显示对应中文提示。
- DEF-029：状态栏增加适度下方留白，并以主题感知的顶部灰色细线明确分隔文档区。
- DEF-030：有序列表按钮必须显示“数字序号＋横线”的列表语义，不得显示单独圆圈。
- DEF-031：深色主题下文档背景、文字、选区和工具栏普通/悬停/按下态均必须使用深色主题调色板，不得残留白底或浅色固定热区。
- DEF-032：无序列表按钮必须显示三组“圆点＋横线”的列表语义。
- DEF-033：建立 Markdown 标记能力清单；表格、链接工具栏入口作为已确认需求登记，允许后续独立任务完成实现与验收。
- DEF-034：新增“清除当前样式”命令，默认快捷键为 Ctrl+\\；实现前需在变更设计中定义行内、块级和混合选区的清除规则。
- DEF-035：直接运行 Release EXE 后应在 10 秒内创建可见主窗口和任务栏图标；进程进入输入空闲，主窗口句柄非零、标题非空且保持响应，不得在窗口创建前枚举或同步发送消息到其他进程窗口。

- DEF-038：冷启动空文档选择“一级标题”后，键盘焦点必须回到文档区，插入点映射到隐藏的 `# ` 之后；直接输入“在”时源码必须为 `# 在`，不得为 `在# `。
- DEF-039：双击、命令行或“最近文件”打开约 50 KB、包含大量标题/行内格式/列表/表格/代码块的 Markdown，必须完成投影并恢复响应；span 位置换算不得对每个 span 重复转换全文前缀，不得在一次投影中重复格式化全部 span，批量格式化期间必须冻结 TOM 布局；活动弹出菜单的命令执行期间不得同步删除/重建该菜单，任何原生菜单删除失败都不得形成循环。
- DEF-040：展开和折叠三角必须以标题字符实际行框垂直居中；展开态尖向下，折叠态尖向右并朝向标题文字。折叠槽必须位于 RichEdit 正常文字区内并可稳定点击，同时保留最左侧原生选行栏的单击选行/双击选段行为；三角与标题文字须保留清晰视觉间距。折叠不得隐藏当前标题自己的行终止换行；隐藏区内图片、表格等自绘层不得残留；下一个同级或更高级标题必须保留在后续独立行。鼠标点击折叠不得移动正文插入点或改变当前文档视口。
- DEF-041：粗体无选区时必须静默无动作，有选区时可连续点击添加/移除且图标亮灯同步；代码块和水平分隔线按钮必须可达，代码块同时进入格式菜单；引用、无序列表、有序列表和任务列表在当前块内须点亮图标；引用显示主题感知的可见灰色竖线；三类列表换行使用悬挂缩进，标记在左且续行与首行正文对齐，RichEdit `dxOffset` 必须为正；渲染风格弹出按钮本身对所有风格均不亮灯。

## 4. 维护规则

- 每次用户反馈先登记或关联既有编号，再修改代码。
- 每次提交必须更新状态、测试证据、提交号和人工验收栏。
- 自动测试通过不等于用户验收；用户未确认时保持“待用户复测”。
- 同类问题再次出现时标记“复发”，不得新建一个看似无关的“已解决”记录掩盖历史。
