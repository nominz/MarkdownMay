## 1. 状态说明

| 状态 | 含义 |
| --- | --- |
| 待处理 | 已登记，尚未开始修复 |
| 处理中 | 已开始分析或修改，尚未完成验证 |
| 自动通过／待用户复测 | 直接回归已通过，但用户尚未明确验收 |
| 用户验收 | 用户已明确确认问题解决 |
| 复发 | 曾修复但用户再次报告同类问题 |
| 阻塞 | 当前无法继续，需要外部条件或用户决定 |

## 3. 本轮验收口径

- DEF-010：菜单窗口四角均被真实窗口区域裁剪，右下角不存在方形像素或阴影尖角。
- DEF-011：文件菜单打开时，鼠标横移到编辑、格式等顶层菜单，无需单击即可切换对应下拉菜单。
- DEF-012：输入 `* ` 和正文后回车，源码自动插入下一行 `* `，渲染区显示下一项目符号；空项目再次回车退出列表。
- DEF-013：输入 `1.` 时保持普通文本，输入空格后成为有序列表；输入正文并回车后源码自动生成 `2. `。
- DEF-014：允许同时运行多个独立顶层窗口，每个窗口拥有自己的单活动文档；双击或命令行打开新文件时新建窗口，不再转发给既有进程。该口径须先进入需求与设计评审。
- DEF-015：在任意两个块之间按 Enter 后，插入点停留在新建空行，后续输入落入该空行，不跳到下一段。
- DEF-016：在长文档中间输入 `* `、正文并按 Enter，必须在当前位置生成下一同级项目，不跳出列表或跳到其他段落。
- DEF-017：对照模式左栏按 Enter 后立即切回渲染模式，切换在可接受时间内完成，窗口保持响应，内容不丢失。

## 4. 维护规则

- 每次用户反馈先登记或关联既有编号，再修改代码。
- 每次提交必须更新状态、测试证据、提交号和人工验收栏。
- 自动测试通过不等于用户验收；用户未确认时保持“待用户复测”。
- 同类问题再次出现时标记“复发”，不得新建一个看似无关的“已解决”记录掩盖历史。
