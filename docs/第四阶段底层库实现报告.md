# 马冬梅第四阶段底层库实现报告

> 文档编号：MM-DEV-004-R  
> 完成日期：2026-07-31  
> 结论：通过阶段验收

## 1. 阶段目标

按照瀑布路线完成不依赖界面的 `markdownmay_core` 静态库。该阶段只建设文件、文档、Markdown 和本地服务底层，不提前进入第五阶段界面开发。

## 2. 已完成范围

1. 文件底层：UTF-8/UTF-8 BOM/UTF-16 识别，换行识别与转换，路径校验，临时文件替换式原子保存。
2. 文档模型：不可变节点树、节点索引、源区间、修订号和结构校验。
3. Markdown：基于 MD4C 的 GFM 解析，Markdown 序列化，未知块保留和语义往返比较。
4. 文档事务：修订号冲突拦截、源码编辑事务、渲染编辑提交、保存状态和事件通知。
5. 节点身份：完整重解析后，对结构未改变的子树复用原节点 ID；修改、新增节点分配新 ID。
6. 本地服务：设置、最近文件、日志和崩溃恢复文件；数据均保存在本地。
7. 图片存储：远程图片不加载不下载；本地图片可引用或复制到 `<文档名>.assets`；删除受管图片时改名为 `del_`，重名递增；撤销不覆盖已存在文件。
