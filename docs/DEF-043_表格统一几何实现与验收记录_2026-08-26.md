# DEF-043 表格统一几何实现与验收记录

> 日期：2026-08-26
>
> 范围：仅统一渲染表格显示几何；不增加行列选择、操作区、移动、拖拽、菜单或快捷键

## 1. 实现结论

- 新增短生命周期 `TableLayout` / `TableCellLayout`，由当前 `RichProjection`、会话修订和 RichEdit 已完成的客户区布局派生；不持有正文，不缓存为第二状态源。
- `ProjectionSpan` 为 table/cell 记录当前语义节点身份和所属表格身份，使多表格布局不再仅靠投影范围猜归属。
- 行文字框使用 TOM `ITextRange2::GetPoint(TA_TOP/TA_BOTTOM)` 读取实际首末行框；相邻行边界取实际行框间空白中点，首末边界纳入既有 100 twip 表格段前/段后。
- 列边界由各列 RichEdit 实际文字起点减去统一 DPI padding 得到，末边界取当前 RichEdit formatting rect 右边界；单元格矩形由行边界与列边界组合。
- 表格 RichEdit 第一列缩进和中间 tab stop 同时加入统一 6 DIP 水平 padding；最后一个尾部 tab stop 保持落在表格右边界。GDI 不再临时向外补偿 5 px。
- `draw_table_grid()` 只消费 `BuildTableLayouts()` 结果，删除控件 DC `GetTextMetrics/tmHeight`、字符点加字体高度、缺列固定 96 px 回退及本地边界数组。
- 表头/斑马纹继续使用 RichEdit `CFM_BACKCOLOR`。本轮没有在 RichEdit 完成文字后用 GDI 填充 cell，以避免覆盖文字或引入第二次文字绘制。
- resize 后仅重放 table span 的段落制表位；投影、滚动、DPI、字体/profile 和编辑均在下一次绘制时重新派生几何，不复用旧 `RECT`。

## 4. 已知边界

- RichEdit `PARAFORMAT2::rgxTabs` 仍最多使用 31 个 tab stop，而 `TableEditor` 允许 100 列；按本轮要求保留为技术债。
- 当前 tab 表格不是独立 cell 排版引擎；长文字可按 RichEdit 整体格式区换行，但不承诺成熟表格控件的逐 cell 独立换行/溢出策略。
- 字符背景仍由 RichEdit span 绘制，严格意义上不是 GDI `cell_rect` 填充；本轮优先保证文字和网格几何一致，避免覆盖文字风险。
