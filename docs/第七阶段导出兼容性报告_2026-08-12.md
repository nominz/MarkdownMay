## 2. 本机能力与未执行项

- 当前 PATH 及常见安装目录未发现 Microsoft Word、WPS Writer 或 WPS Office，因此未执行 DOCX 的真实打开、编辑、保存、图片移动独立性和打印预览。
- 当前 Windows 应用自动化连接因本机权限错误无法建立，因此未执行导出对话框的逐按钮人工点击和取消时序观察；相关命令分派与设置持久化只由自动集成测试覆盖。
- HTML 已在本机 Chromium 内核验证同一生成物，但尚未执行真实 `file://` 双击、Edge/Chrome 多版本、打印预览和断网监测矩阵。
- PDF 尚未执行 Windows 10/11 多阅读器、真实打印机、高对比度、DPI 和大图片人工矩阵。
- 10 MB 文档的端到端 UI 响应、峰值内存和取消延迟尚未形成可复核性能证据。

上述未执行项目不得写成“通过”。用户已明确接受 PDF 非阻断偏差并批准 Word 导出功能通过，剩余跨软件、打印、性能与 UI 完整矩阵属于第八阶段“完整系统测试”的正式范围，不再阻止第七阶段功能实现封闭。

## 3. 第八阶段继续验证项

1. 在安装受支持 Word 与当前常用 WPS 的 Windows 环境完成 DOCX 打开、编辑、保存、样式、列表、表格、链接、图片和打印预览矩阵。
2. 在受支持浏览器完成 HTML 本地文件、零网络、打印预览及 Mermaid/公式失败回退矩阵。
3. 对 PDF 完成多阅读器、打印、高对比度/DPI、真实图片检查。
4. 对 10 MB 文档记录 UI 响应、总耗时、峰值内存和取消延迟。
5. 实际操作统一导出入口的七种组合、默认项恢复、成功/失败/取消提示，并确认文档路径、脏状态和编码不变。
