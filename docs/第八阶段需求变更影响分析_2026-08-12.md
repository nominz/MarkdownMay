# 第八阶段需求变更影响分析

> 文档编号：MM-CR-2026-014-020；日期：2026-08-12；状态：随 V05 1.2 受控修订批准冻结

## 1. 变更摘要

第八阶段把 V04 的文档组合能力收口，并新增 TXT 正式文档、`.md/.txt` 候选程序管理和两类文档图标。切分不改变会话且不可撤销；插入是 `DocumentSession` 单次可撤销事务。

## 2. 影响矩阵

| 维度 | 影响与处理 |
| --- | --- |
| 需求 | 新增 SPLIT、INSERT、TXTDOC、ASSOC、ICON；V04 COMBINE 在冲突处由 V05 细化 |
| UI | 文件菜单增加切分/插入；设置增加关联状态与默认应用引导；TXT 禁用 Markdown 专属命令并说明 |
| 文档模型 | 不新增正文模型；`DocumentSession` 增加文档类型元数据；插入复用应用级事务 |
| Markdown | Markdown 插入需预解析、边界换行、链接与图片计划；TXT 不进入 Markdown 解析/渲染 |
| 三模式 | 抽取统一插入点到 UTF-8 源偏移服务；TXT 仅源码式表面 |
| 文件 | 切分结果继承当前文档类型；新增双新目标提交、来源解码和文档类型路由；来源静默解码为内部 UTF-8，保存统一转为当前编码/换行 |
| 图片 | Markdown 插入复制到 `.assets` 并回滚；TXT 插入不识别图片语义 |
| 导出 | Markdown 导出不变；TXT 只允许全文 TXT 规范化副本，禁用语义导出 |
| 平台 | 两 ProgID、Capabilities/OpenWith、默认应用设置跳转、Shell 通知、三类嵌入图标 |
| 便携安置 | 新增自复制事务、目标文件夹对话框、受控重启参数；安置后复用候选关联修复，不删除原 EXE |
| 非功能 | 10 MB 响应、注册表最小权限、路径/编码安全、单 EXE；Word/PDF 读取路线须单独做依赖/许可证/体积审查 |
| 测试 | UTF-8/CRLF、结构切分、双目标补偿、撤销、TXT 路由、注册表隔离、图标/DPI |
| 文档 | 更新 V05、总体/详细设计、功能矩阵、命令/错误码、阶段矩阵；封闭时更新用户文档 |

## 3. 核心设计影响

1. `DocumentSession` 仍保存唯一 UTF-8 正文，仅新增 `DocumentKind { markdown, plain_text }`。
2. `SourcePositionMapper` 集中处理三模式插入点映射和修订门禁。
3. `DocumentSplitService` 读取固定快照，首版只创建两个不存在的新目标，以可补偿协议实现完整成功/失败。
4. `DocumentCombineService` 先生成不可变插入计划，再准备资源并通过一次会话事务提交。
5. `FileAssociationService` 扩展为按文档类型声明式注册计划；UI 不直接写注册表。
6. 图标以资源 ID 嵌入 EXE，注册表只引用 `exe,index`。
7. DOCX/PDF 读取不复用现有 writer；先建立 8.3B 风险样机，仅在安全、体积和中文提取质量通过后正式化 reader。
8. `ApplicationPlacementService` 只负责路径校验、临时复制、刷新、字节校验与原子提交；UI 负责确认和错误呈现，`StartupCoordinator` 负责等待旧 PID 后启动。

## 4. 风险与控制

| 风险 | 控制 |
| --- | --- |
| 两目标无法真正跨文件原子提交 | 禁止覆盖既有目标；任一失败补偿删除，并对清理失败给出严重诊断 |
| 光标映射到过期修订 | 统一映射服务验证 view/session revision，失败时禁用 |
| 插入资源半成功 | 资源日志 + 正文单事务 + 反向补偿；不删除非本事务文件 |
| TXT 被误当 Markdown | 打开时冻结文档类型，纯文本不进入 Markdown 语义命令 |
| 破坏默认程序 | 只注册候选，永不写 UserChoice；最终选择完全交给用户和 Windows |
| DOCX/PDF 导入扩大范围 | 先样机后实现；只承诺文字提取，不承诺版式；扫描 PDF 无 OCR 并明确拒绝 |
| 单 EXE 后图标失效 | ICO 编入资源并用稳定索引引用 |
| 复制后关联仍指向旧位置 | 新进程退出等待完成后调用既有声明式关联注册；继续禁止写 `UserChoice` |
| 新进程被旧单实例截获 | 内部 `--wait-for-process` 参数在单实例仲裁之前等待旧 PID 退出 |
| 覆盖错误目标或留下半文件 | 规范路径比较、显式覆盖确认、同目录独占临时文件、刷新和逐字节校验后原子替换 |

## 5. 不受影响范围与结论

PDF/DOCX/HTML writer 算法、MDM、多标签、ANSI 猜测、应用内 Mermaid/公式渲染不受影响。第七阶段 PDF 精修仍留第十阶段。基础 `.md/.txt` 插入和安置功能均无需新依赖或第二正文模型；DOCX/PDF 输入是已撤销的独立 8.3B 风险增量。用户已批准本分析及 8.8 修订。
