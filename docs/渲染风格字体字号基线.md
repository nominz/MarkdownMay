## 1. 用途

本文是“宋盈、元朗、明正、清晰”四种渲染风格的人工维护基线。以后可以直接指定按本文调整渲染效果；每次调整都必须同步需求、设计、`editor/render_style.cpp` 和 `render_style_unit` 测试。

本文不是应用运行时配置文件。`MarkdownMay.exe` 不读取或携带本文，继续保持 Windows 原生单 EXE；字体只引用 Windows 已安装字体，不下载、不嵌入、不分发字体文件。

## 3. 固定边界

- 风格仅作用于 Markdown 的 RichEdit 渲染表面；源码模式字体不随风格改变。
- 对照模式只改变右侧渲染表面。
- 字体与颜色主题相互独立。
- 切换风格不得修改 Markdown、`DocumentSession`、撤销历史、文件内容、选区或逻辑插入点。
- 四个稳定内部 ID 和默认风格“元朗”保持不变。

## 4. 后续修改方式

以后需要调整时，可以直接说明“按《渲染风格字体字号基线.md》修改某个风格”，并给出新的字体或字号。实现时以本文更新后的表格为准，同步代码、自动测试和受影响的正式需求与设计文档。
