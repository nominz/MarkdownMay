## 1. 已进入正式基线的决定

- 默认新文档使用 UTF-8 无 BOM；换行默认 CRLF，打开已有文件时识别并尽量保留原编码和换行。
- 删除文内受管图片引用时不删除文件，而是在文件名前增加 `del_`；粘贴图片前必须先保存文档，图片进入 `<文档名>.assets`。
- 远程图片永不由马冬梅下载、缓存或显示，只保留地址并显示安全占位。
- 默认模式是可编辑渲染模式；源码模式可编辑但不渲染；对照模式左侧源码可编辑、右侧渲染只读。
- 当前产品是原生轻量单活动文档应用；使用单 EXE，文件放在任意目录仍可按当前绝对路径注册为 Markdown 候选程序。
- 文件关联只写当前用户允许范围，不篡改 Windows `UserChoice`，最终默认程序由用户在系统界面确认。
- 当前代码采用 MIT 许可证、免费和公开源代码。许可证将来可以对新版本变更，但已经按 MIT 获得的旧版本授权不能靠删许可证追回。
- Git 默认只做本地提交，不因暂时不能 push 阻断开发。

## 3. GitHub 与发布边界

- 公开仓库无法禁止别人 clone、下载 ZIP 或复制源代码；MIT 也允许复制和分发。
- 改为私有只能限制未来访问，不能收回别人已经取得的本地副本或既有公开 fork。
- 如果将来只发布 EXE、不公开源码，就不再是当前意义上的开源项目。
- 用户目前没有要求改变 MIT、仓库可见性或拆分仓库，因此不得主动执行这些外部变更。
