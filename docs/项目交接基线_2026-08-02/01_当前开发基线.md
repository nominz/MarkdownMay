# 当前开发基线

## 1. 产品定位与永久边界

- 中文名：马冬梅；英文名：Markdown May。
- 目标用户：不安装 VS Code、不配置插件的 Windows 办公用户。
- 技术栈：C++20、Win32、RichEdit/TOM、Scintilla、MD4C、CMake、MSVC。
- 发布方向：便携、轻量、单 EXE；允许系统 DLL，不引入 Electron、WebEngine 或运行时插件体系。
- 本地优先：无账号、无广告、无云服务、无遥测；远程图片不下载、不缓存、不显示。
- 三种模式共用一个 `DocumentSession`：可编辑渲染模式、可编辑源码模式、左源码可编辑/右渲染只读的对照模式。
- 许可证：当前为 MIT；GitHub 仓库为公开仓库 `nominz/MarkdownMay`。

## 2. 已完成能力

### 文档和 Markdown

- UTF-8 无 BOM 默认新文档；识别 UTF-8 BOM、UTF-16 LE/BE 和 CRLF/LF/混合换行。
- 原子保存、保存重开、原文保留、只读文件、外部修改检测和未保存确认。
- 标题、段落、粗体、斜体、删除线、行内代码、链接、引用、代码块、分隔线、列表、任务列表、表格、图片及安全原始 HTML 显示。
- 本地图片进入 `<文档名>.assets`；文内删除受管图片时文件改名增加 `del_`，不物理删除。
- 远程图片只显示阻止加载占位，不发起网络请求。

### 应用能力

- 中文原生主窗口、菜单、快捷键、工具栏、状态栏和三模式切换。
- 新建、打开、保存、另存为、拖放、最近文件、文件打开队列。
- 命令行、多路径、单实例和当前用户范围的文件关联注册/修复/撤销。
- 跟随系统、浅色、深色和高对比度；Per-Monitor V2 DPI，覆盖 100%～300% 缩放规则。
- Windows 标准打印和页面设置；RichEdit 原生分页打印。
- UTF-8 INI 本地设置 V2：主题、默认视图、打印方向和四边页边距；保留未知键并迁移 V1。

## 3. 代码目录责任

| 目录 | 当前责任 |
| --- | --- |
| `src/document` | 文档、节点、事务、修订和唯一会话状态 |

| `app` | 入口、生命周期、命令分发、对话框和业务编排 |

| `prototype` | 第三阶段风险样机；不是正式应用实现入口 |

## 4. 构建与验证基线

环境：Windows、CMake、Visual Studio Build Tools/MSVC。

```powershell
cmake --preset windows-x64-debug
cmake --build --preset windows-x64-debug --config Debug
ctest --test-dir build/windows-x64-debug -C Debug --output-on-failure --timeout 60

cmake --build --preset windows-x64-debug --target MarkdownMay --config Release
```

正式 Release 程序：

```text
build/windows-x64-debug/app/Release/MarkdownMay.exe
```
