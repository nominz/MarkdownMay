## 7.3 验收记录

### 实现范围

- `CancellationSource/Token` 使用共享原子状态，writer 可分块观察取消；默认 token 表示未取消。
- `ExportProgress` 冻结为 preparing、writing、validating、committing、completed 五阶段；公共 reporter 保证完成量不倒退并隔离 progress sink 异常。
- `ExportWriter` 只接收固定 `ExportDocument`、预留临时路径、取消 token 和进度 sink，不接收最终目标路径。
- `ExportValidator` 只检查 writer 完成的临时文件；验证成功且未取消后才允许提交。
- 临时文件使用 `CREATE_NEW` 在目标同目录预留不可预测的进程/序列名，RAII 在全部失败和取消路径清理。
- 提交复用 Windows `ReplaceFileW`/`MoveFileExW` 及 write-through 语义；只有提交成功后才释放临时文件所有权。
- writer 成功后由公共管线重新打开临时文件并执行 `FlushFileBuffers`，各格式 writer 不承担最终耐久性门禁。
- 6002、6003 的既有文档错误码正式补入 C++ 枚举；新增 6005 `export_validation_failed`，不复用已冻结编号。

## 7.4A 受控前置增量

### 增量原因与边界

7.5 预研验证发现，原 7.1 快照没有文档基准路径及冻结图片字节，PDF writer 无法在导出开始后的编辑或文件变化下稳定满足 PDF-004、PDF-006；同时 MD4C 已具备但项目未启用公式 span，EXT-002、EXT-008 缺少语义输入。经用户批准增加本前置增量，不变更 V04 功能范围，不实现 PDF/DOCX/HTML writer 或 UI。

### 实现范围

- 启用 MD4C `MD_FLAG_LATEXMATHSPANS`，增加行内/块公式节点；节点只保存源码、类型与源范围，不解析、不执行、不排版。
- Markdown writer 原样恢复 `$...$`/`$$...$$`，确保三模式共用语义文档和源码往返边界不变。
- `ExportContext` 只在创建固定修订快照时提供文档路径和资源上限；不向 `DocumentSession` 增加第二套路径或正文状态。
- 全文 `ExportDocument` 按图片 NodeId 冻结本地文件字节，并记录 `embedded`、`remote_blocked`、`missing`、`too_large` 状态；仅大纲不读取图片。
- 单资源默认上限 32 MiB、累计默认上限 64 MiB；远程图片不联网，缺失和超限均显式保留状态供格式 writer 降级或失败。
- TXT 补充行内/块公式类型标识和源码输出，修正 7.4 在公式语义启用后的追溯闭包。
