## 7.1 验收记录

### 实现范围

- `ExportScope` 冻结为 `outline/full`，`ExportFormat` 冻结为 `pdf/docx/txt/html`。
- 组合门禁拒绝 `outline × html`，允许 V04 的其余七种组合。
- `BuildExportDocument` 只接收一次 `SessionSnapshot` 和期望修订。
- 创建前验证语义存在、源码/解析/期望/语义修订一致且文档快速不变量通过。
- `outline` 递归筛选 H1～H6，保持源顺序、真实层级、NodeId 和源范围。
- `full` 复制根节点下全部块及其行内/子结构。
- 导出节点使用拥有型值和递归容器，不持有 `Document`、`Node*` 或任何 UI 对象。

## 7.2 验收记录

- 单文件 HTML 样机不包含伴随资源、脚本节点或外部资源属性；结构测试通过。
- 严格 CSP 禁止默认资源、脚本、连接、字体、对象、base 和表单提交。
- 攻击标签只作为可见文字保留，真实浏览器 DOM 未出现攻击脚本/图片节点或执行标记。
- Mermaid 当前显示明确源码回退；浏览器无原生 Mermaid 能力，固定渲染资源必须先通过许可证、安全、CSP、体积和单 EXE 审查。
- MathML 在当前浏览器使用 Windows `Cambria Math` 完成分式、根式和上标二维排版，基础系统字体路线通过风险验证。
- 浏览器安全策略禁止自动化直接打开 `file://`；本轮通过仅监听 `127.0.0.1` 的临时只读服务验证同一构建产物，结束后服务已停止。真实双击文件进入后续人工兼容性测试。

完整证据见 `第七阶段7.2_HTML安全与公式系统字体风险验证报告.md`。本增量没有实现正式 HTML writer、LaTeX 转 MathML 解析器或 Mermaid 绘图，不得据此声明用户导出功能可用。

## 7.3 验收记录

### 实现范围

- `CancellationSource/Token` 使用共享原子状态，writer 可分块观察取消；默认 token 表示未取消。
- `ExportProgress` 冻结为 preparing、writing、validating、committing、completed 五阶段；公共 reporter 保证完成量不倒退并隔离 progress sink 异常。
- `ExportWriter` 只接收固定 `ExportDocument`、预留临时路径、取消 token 和进度 sink，不接收最终目标路径。
- `ExportValidator` 只检查 writer 完成的临时文件；验证成功且未取消后才允许提交。
- 临时文件使用 `CREATE_NEW` 在目标同目录预留不可预测的进程/序列名，RAII 在全部失败和取消路径清理。
- 提交复用 Windows `ReplaceFileW`/`MoveFileExW` 及 write-through 语义；只有提交成功后才释放临时文件所有权。
- writer 成功后由公共管线重新打开临时文件并执行 `FlushFileBuffers`，各格式 writer 不承担最终耐久性门禁。
- 6002、6003 的既有文档错误码正式补入 C++ 枚举；新增 6005 `export_validation_failed`，不复用已冻结编号。

## 7.4 验收记录

### 实现范围

- 新增 `WriteTxt`、`ValidateTxt` 和 `ExportTxt`，通过 7.3 公共任务管线写入、验证并原子提交，不直接写最终目标。
- 仅大纲按标题源顺序输出，使用每级两个空格表达真实 H1～H6 层级，不带 Markdown 标记。
- 全文按语义树输出标题、段落、引用、嵌套有序/无序/任务列表、代码块、表格、分隔线和原始 HTML 提示；表格使用制表符分列。
- 行内强调等样式只保留可见文字；链接和图片同时保留可见说明与目标地址，避免纯文本导出丢失目标信息。
- Mermaid 代码块明确标记为“Mermaid 源码”并保留源码，不把源码伪装成已渲染图形。
- 输出固定为 UTF-8 无 BOM、CRLF 换行；验证器拒绝 BOM、非法 UTF-8 和孤立 LF/CR。
- 当前 Markdown 解析基线尚未启用公式扩展，因此本增量不虚构公式节点支持；后续启用语法时须补充 TXT 公式回归。
