# CR-2026-034 渲染行距与空行折中策略影响分析

## 1. 用户决定

建立《马冬梅渲染风格行距基线》，放松四种风格的行距并定义段前、段后和标题间距；空行采用“标准结构空行折叠为段距、额外连续空行仍可编辑”的折中策略。

## 2. 影响范围

| 维度 | 结论 |
| --- | --- |
| 需求/UI | 渲染模式和对照右栏纵向排版变化；源码模式不变 |
| 文档模型 | `DocumentSession` 和源码不变，不建立第二套正文 |
| Markdown | 投影把块间两个标准行终止合并为一个可见换行，并让该边界覆盖完整源码间隔；额外换行与代码块内部换行保持可见 |
| 编辑/撤销 | 合并后的投影边界仍有稳定源码映射；删除和合并继续走既有单事务同步 |
| 文件/编码 | 保存与换行风格不变；投影同时识别 LF、CRLF 和 CR 行终止 |
| 三模式 | 渲染及对照右栏应用；源码及对照左栏原样显示 |
| 图片/导出 | 无影响；本轮仅调整屏幕 RichEdit 投影 |
| 平台/非功能 | 使用 RichEdit 原生段落格式；无依赖、网络、WebEngine 或运行时下载 |
| 测试 | profile 数值、投影折叠/额外空行/映射、RichEdit 行距段距、删除同步、Debug/Release 回归 |

## 3. 风险与门禁

主要风险是合并边界删除时吞入相邻块、实时输入重复同步、标题/代码块格式覆盖以及大文档逐段格式调用。实现必须让单个可见边界映射完整标准源码间隔、逐个保留额外行终止，并以全文一次应用普通段距、标题定向覆盖避免逐段退化；同步消息必须合并，用户实机确认主观疏密后才能把初始数值记为视觉通过。
