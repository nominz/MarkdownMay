# 马冬梅命令编号表

## 1. 使用规则

- 菜单、工具栏、快捷键和其他命令入口必须复用本表中的 `CommandId`，不得各自定义编号。
- UI 入口只调用 `CommandDispatcher::query/execute`，不得直接修改文档或编辑器。
- 已登记但尚未实现的命令必须显示为禁用，不得伪装成功。
- 编号一经进入主干不得改作其他含义；废弃时保留编号空洞。

## 3. 可用性上下文

当前分发器依据活动模式、撤销栈和重做栈查询命令状态：

- 撤销、重做分别由应用级历史栈决定是否启用；
- 格式命令只在可编辑渲染模式启用；
- 三种模式命令始终可请求，当前模式显示选中标记；若文档内容暂时不能进入渲染模式，执行结果由中文错误提示处理；
- 新建、打开在文档有未保存修改时暂时禁用；第六阶段增量5接入保存/放弃/取消确认后再允许进入确认流程；
- 查找、替换在对应界面接入前保持禁用。
