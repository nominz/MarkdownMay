## 实现范围

| 项目 | 实现 |
| --- | --- |
| 四种风格纵向参数 | `RenderStyleProfile` 增加最小行距、普通段距及 H1～H6 段前/段后 |
| 原生排版 | RichEdit 全文一次应用普通段落格式，标题 span 定向覆盖标题段距 |
| 标准空行 | 语义块末尾两个标准行终止投影为一个可见换行，映射覆盖完整源码间隔 |
| 额外空行 | 三个及以上连续行终止时，前置额外行终止逐个投影，最后两个作为标准间隔合并 |
| 实时同步 | 投影期间抑制 RichEdit 变更/选区通知，`ViewModeController` 合并重复同步消息 |
| 可维护基线 | `docs/马冬梅渲染风格行距基线.md` 记录可人工修改的全部初始参数 |

## 用户实机验收

以下项目不以自动化结果代替人工判断：

1. 宋盈、元朗、明正、清晰四种风格的正文行距和标题间距是否舒适；
2. 普通 Markdown 结构空行是否不再形成可单独选择的空白行；
3. 连续增加第三个及后续换行后，额外空行是否可见、可选、可删；
4. 在段落、标题、列表和 `---` 附近连续输入是否无跳字、重复同步或卡顿。
