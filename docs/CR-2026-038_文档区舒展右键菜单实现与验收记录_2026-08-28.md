# CR-2026-038 文档区舒展右键菜单实现与验收记录

## 1. 用户目标与范围

文档区增加类似 Windows 11 记事本的鼠标右键菜单，但不复制 Bing 搜索、拼写和插入表格。用户特别要求菜单宽松、大气，不能使用窄小弹层或低矮菜单项。

## 2. 受控基线

- 《需求规格说明书 V07》升级至 1.8，新增 CTXMENU-001～005。
- 总体设计与详细设计新增 CR-2026-038 / DC-2026-018。
- `DocumentSession` 仍为三模式唯一正文；本变更不修改文件格式、编码、换行、导出、恢复或系统集成。

## 3. 实现

- 新增共享 `DocumentContextMenu`，使用原生 `TrackPopupMenuEx` 与 owner-draw 菜单项。
- 普通项基线为 304×44 DIP，提供图标区、标签区、右侧快捷键区和三组层级。
- 固定命令：撤销、重做、剪切、复制、粘贴、删除、全选。
- 渲染、源码和对照两侧均接入；对照右侧只读表面只允许复制和全选。
- 能力状态来自当前选区、应用撤销历史、只读状态及 Unicode 文本剪贴板。

- Debug `ALL_BUILD` 成功；Debug 全量 46/47。
- Release 除标准主程序因既有 Release 进程占用而无法覆盖外，其余目标完成；独立 `MarkdownMay-context-menu.exe` Release 候选生成成功。
- Release 全量 46/47；新增 `view_modes_integration` 删除选区同步在 Debug/Release 均通过。
- 两配置唯一失败均为进入本任务前已存在且在 DEF-048 记录中的 `block_interaction_integration` 退出码 14，本变更未将其记为通过。
- 已在 Debug 实窗以鼠标右键检查：菜单宽约 348 屏幕像素、七个普通项各约 44 像素，图标、标签、快捷键和两处分组清晰；空文档正确禁用撤销/重做/剪切/复制/删除并允许粘贴/全选，无 Bing、网络搜索、拼写或插入表格。
- 浅色 100% DPI 实窗观感已复核；深色、高对比度及 125%～300% DPI 仍保留为人工兼容性复核项。

## 5. DEF-049：选中文字后剪切/删除被禁用

- 用户实测发现非空选区上右键后“剪切”“删除”仍禁用。
- 根因是原生编辑控件可在 `WM_RBUTTONDOWN` 默认处理期间先折叠选区，而菜单能力在随后的 `WM_CONTEXTMENU` 才查询。
- 修复在右键按下时判断鼠标是否命中原选区；命中时暂存并在菜单查询前恢复选区，选区外右键不恢复。
- `view_modes_integration` 新增“保存选区→模拟原生折叠→菜单前恢复”的 RichEdit 回归，Debug 定向通过。

## 6. DEF-050：表格之后选区命令整体错位

- 用户在真实 V04 文档确认：剪切后蓝色选区跳到下一段，引用失败，代码块作用到上方相隔段落。
- 根因一：原生 RichEdit table/cell/row 有独立物理位置；旧的引用、代码块等命令却以展平 `EM_GETTEXTRANGE` 前缀长度索引普通投影，越过表格后产生累计前漂。
- 根因二：事务重投影沿用修改前的控件 `CHARRANGE`，没有把事务产生的新源码选区重新映射到新投影。
- 修复统一使用 `BuildPhysicalPositions → MapControlSelection`，并新增 `project_editor_selection()` 在事务后恢复 `ParagraphEditor` 的逻辑选区。
- 新增包含原生表格的定向回归：表格后目标段落引用、代码块和剪切只作用于目标；剪切及格式事务后选区按新文档位置恢复。Debug/Release 三项定向均通过。
- Debug `ALL_BUILD` 成功，全量 46/47；唯一失败仍为既有 `block_interaction_integration` 退出码 14。独立 Release 主程序构建成功，相关 Release 定向 2/2 通过。

## 7. DEF-051：文末引用撤销跳到文首并残留半行文字

- 根因一：`ViewModeController::undo/redo` 先提交完整历史源码，再由 `RefreshActive` 从仍是旧内容的 RichEdit 投影捕获选区；新源码较短时映射失败并回退 `{0,0}`，恢复选区时把视图滚到文首。
- 根因二：RichEdit 重投影解冻后仅异步 `InvalidateRect`，没有同步擦除完整客户区，文档缩短或滚动边界变化时底部可能残留旧帧半行文字。
- 修复在历史提交前捕获逻辑源码选区和滚动比例；新投影恢复选区后同步擦除历史刷新产生的旧帧，再恢复滚动位置。同步重绘只限 undo/redo 刷新，标题折叠仍沿用自身异步滚动保护。
- 新增 180 段长文档文末“引用→撤销”回归，断言源码精确还原、选区仍在文末且滚动位置不跳回开头；Debug 定向通过。
