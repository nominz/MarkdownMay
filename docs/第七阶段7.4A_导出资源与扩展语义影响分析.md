# 第七阶段 7.4A 导出资源与扩展语义影响分析

> 日期：2026-08-12
>
> 授权：用户同意增加受控前置增量

## 1. 原因

7.5 PDF 预研样本已验证基础 PDF 结构、分页和中文文本路线，但暴露两个硬依赖：不可变导出模型没有冻结本地图片资源；项目未启用 MD4C 公式 span。继续写 PDF 会无法满足 PDF-004、PDF-006 和 EXT-008，故撤回实验 writer，不形成伪完成提交。

## 2. 影响与决定

| 层次 | 影响 | 决定 |
| --- | --- | --- |
| 需求 | V04 已要求图片和公式源码 | 不升版、不扩范围 |
| 文档模型 | 公式需稳定类型与源码 | 新增两种只保存源码的 NodeKind，仍属于唯一 `DocumentSession` 语义树 |
| 导出模型 | 图片必须不受导出后文件变化影响 | 创建快照时解析并复制有界字节，不让 writer 延迟读取 |
| 安全 | 远程图片、缺失文件、超限资源 | 不联网；冻结显式状态；由格式 writer 按条款失败或降级 |
| TXT | 7.4 在公式启用后需要闭包 | 输出明确类型标识和源码 |
| PDF/DOCX/HTML | 依赖本增量 | 本增量不实现格式 writer |

## 3. 门禁

- 本地资源冻结后删除或改变原文件，不得改变已有 `ExportDocument`。
- 远程图片不得发出请求。
- 公式解析只识别边界并保留源码，不执行 LaTeX。
- 仅大纲不读取图片。
- 完成定向、往返、Debug 全量、Release 构建后才允许提交，并在此基础上重新进入 7.5。
