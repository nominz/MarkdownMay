## 2. 已确认但尚未实现的工具栏能力

1. 表格按钮：调用既有 GFM 表格插入/编辑能力；具体默认行列数和后续弹窗交互另行设计。
2. 链接按钮：对选中文本设置/编辑链接；无选区时的链接文字和地址输入方式另行设计。
3. 清除当前样式按钮：快捷键确定为 `Ctrl+\\`，不用 `Ctrl+Space`。实现前必须明确：
   - 仅清除行内格式，还是同时把标题、引用、列表恢复为正文；
   - 空插入点、单一选区、跨块混合选区的行为；
   - 链接、图片、表格等有数据对象是否允许被“清除样式”破坏。

## 3. 明确不纳入当前标记范围

- 下划线：标准 Markdown 没有统一语法，当前按钮和命令是“删除线”，不是下划线。
- 笔记库专有标记、双向链接、知识图谱、项目管理语法：不属于当前轻量版边界。
- 依赖 WebEngine、在线服务或运行时下载的扩展语法：不采用。

## 4. 变更控制结论

- 本清单不替代《需求规格说明书》，其作用是把 V02 已规定能力和当前入口差距集中呈现。
- 表格、链接工具栏入口属于既有 Markdown 能力的 UI 补全，可在后续独立增量中设计、实现和验收。
- “清除当前样式”是新增命令语义，必须先同步需求与详细设计，再进入实现。
- 大纲仍按独立 V03 变更流程处理，不与本清单中的工具栏缺陷混合实施。
