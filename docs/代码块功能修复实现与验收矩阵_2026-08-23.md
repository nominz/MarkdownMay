### 2026-08-24 DEF-042 真实鼠标复现与根因修正

- 上述“仅为旧交付混用”的判断被用户在候选版中的截图否定；通过 Windows 真实鼠标三击仅选中目标正文后，候选版稳定复现 opening fence 落入 preceding heading。
- 工具栏分派前真实 selection 未丢失。错误发生于 `RichEditHost::toggle_code_block()` 的控件位置到投影位置换算：`CHARRANGE` 将 RichEdit 段落结束符按一个逻辑位置计数，但 `ReadWide()` 返回 CRLF 两个字符；用 `cpMin/cpMax` 直接切割返回文本会随前置换行数累积向前漂移。
- 真实现场中，正文 selection 的 source start 被错误映射到 heading 末尾“侧写”内，随后 `SelectedTopLevelBlocks()` 正确地把已相交的 heading 扩展为完整行；因此表象是 fence 位于 heading 前，根因不是 section 推断。
- 修正为与其他编辑命令一致，使用 RichEdit `EM_GETTEXTRANGE` 驱动的 `PrefixUtf8Size()` 换算 `cpMin/cpMax`，确保控件位置与读取范围使用同一坐标系。
- 回归 fixture 增加真实文档前置多个块、多个换行、中文长正文和段内粗体，防止短文档再次掩盖累积漂移。
- Debug 定向测试 1/1、Release 相关测试 3/3 通过，Release `ALL_BUILD` 成功。
