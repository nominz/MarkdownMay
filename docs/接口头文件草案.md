## 3. 契约规则

1. 接口参数默认不转移所有权；转移时显式使用值或智能指针。
2. 语义文档跨线程只使用 `shared_ptr<const SemanticDocument>`。
3. `Utf8Text` 是内部 Markdown 文本编码；Win32 UTF-16 只存在于平台和 UI 边界。
4. `SourceRange` 使用 UTF-8 字节偏移，不使用 UTF-16 单元或视觉字符数。
5. 所有异步结果带文档 ID 和修订号；旧版本结果必须丢弃。
6. 预期失败通过 `Result<T>`/`Status` 返回，不用异常。
7. 接口析构函数虚拟且无异常。
8. UI 对象不得跨线程。
9. 文件路径使用 `std::filesystem::path`，传入 Win32 时取宽字符表示。
10. 草案中的容器和字段可以在详细实现中优化，但语义和所有权不得改变。

## 4. 尚未编码但已冻结的接口语义

- `IDocumentSession::can_export()` 只有在当前源码修订已成功解析时返回真；
- `accept_parse_result()` 必须拒绝不属于当前文档或已经过期的结果；
- `switch_to(render)` 在源码解析无效时返回错误并保持当前模式；
- `IImageStore` 只对受管图片执行 `del_` 重命名；
- `IFileService::save_atomic()` 成功前不得修改目标文件；
- `IExportService` 只处理固定的不可变语义文档快照；
- 文件关联接口只操作当前用户范围；
- 恢复服务不得把正文写入日志。

## 5. 编码前必须补全

- `ErrorCode` 的正式枚举值；
- 节点属性从通用字段细化为类型安全结构；
- 解析任务调度器和 UI 回调接口；
- 编辑事务操作的 variant 定义；
- 文件身份和外部修改结构；
- PDF/DOCX 选项的完整字段；
- UI Automation 的自定义图片、表格接口；
- 每个方法的前置条件、线程要求和复杂度上限注释。
