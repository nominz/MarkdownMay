# 马冬梅错误码表

> 文档编号：MM-ERR-001
> 版本：1.0
> 代码草案：`design/include/markdownmay/error_codes.hpp`

## 1. 编码规则

错误码是稳定的十进制整数，写入日志、测试报告和用户反馈。已经发布的含义不得复用。

| 范围 | 子系统 |
| ---: | --- |
| 0 | 成功 |
| 1000～1499 | 应用 |
| 1500～1999 | UI |
| 2000～2999 | 编辑器和三模式 |
| 3000～3499 | 文档模型 |
| 3500～3999 | Markdown |
| 4000～4999 | 文件和编码 |
| 5000～5999 | 图片 |
| 6000～6199 | 导出通用 |
| 6200～6399 | PDF |
| 6400～6599 | DOCX |
| 7000～7099 | 注册表和 Shell |
| 7100～7199 | 单实例 IPC |
| 7200～7999 | 其他平台功能 |
| 8000～8099 | 设置 |
| 8100～8199 | 恢复 |
| 8200～8999 | 其他服务 |
| 9000～9999 | 致命错误 |

严重级别：

- `Info`：操作结果提示，不是失败；
- `Warning`：部分操作未完成，但文档安全；
- `Error`：当前操作失败，应用可继续；
- `Fatal`：无法维持进程不变量，需要安全退出。

## 10. UI 文案规则

用户对话框不直接显示枚举符号，可以在“详细信息”显示数字错误码。模板示例：

```text
标题：无法保存文档
说明：原文件没有被修改。请检查磁盘空间或改用“另存为”。
错误码：4007
操作：重试 / 另存为 / 取消
```

禁止：

- 直接显示 HRESULT 而无中文说明；
- 用“未知错误”覆盖已有稳定错误码；
- 在错误参数中包含文档正文；
- 因日志失败再次弹出错误形成循环。
