## 4. 语义冻结

- 只有英文半角 `?` 和 `*` 在勾选“使用通配符”时具有通配符语义；中文 `？` 永远是普通文字。
- `?` 匹配一个 Unicode 字符；`*` 贪婪匹配同一段内零个或多个字符，不跨 CR/LF。
- `^p` 匹配 CRLF、LF 或 CR；替换中的 `^p` 写入内部 LF，文件保存层再应用目标换行策略。
- `^t` 匹配或插入 U+0009，即键盘 Tab 产生的制表符。
- 零长度匹配不参与查找和全部替换，避免仅含 `*` 的模式无限循环。

## 5. 启动阻塞缺陷修复（2026-08-10）

- 现象：Release 进程存在但无主窗口、任务栏图标或主窗口句柄，CPU 空闲。
- 根因：应用在创建主窗口前应用主题；`FindReplaceBar::apply_appearance` 在 `bar_ == nullptr` 时调用 `EnumChildWindows(nullptr, ...)`，Windows 将其解释为枚举桌面顶层窗口，后续跨进程同步发送 `WM_SETFONT` 导致启动线程阻塞。
- 修复：查找栏尚未创建时只记录 DPI 并立即返回；创建完成后的正常主题应用才枚举本栏子控件。
- 回归要求：Debug/Release 主程序均须真实启动到输入空闲，主窗口句柄非零、标题非空且进程响应正常。
- 实际证据：Debug `app_shell_integration` 通过；Debug 全量 34/36（仍为两项既有失败）；Release 构建通过并真实启动，`WaitForInputIdle(10000) == true`、窗口句柄非零、标题“无标题 - 马冬梅”、`Responding == true`。
