## 1. 用途

本文是宋盈、元朗、明正、清晰四种渲染风格的纵向排版人工维护基线。以后可以直接指定按本文调整行距、段前、段后或标题间距；修改时同步需求、设计、`editor/render_style.cpp` 和自动测试。

本文不是运行时配置文件。程序不读取或携带本文，继续保持 Windows 原生单 EXE。

## 4. 空行折中策略

- 两个 Markdown 语义块之间末尾的两个标准行终止，在渲染投影中合并为一个可见换行，由段后/段前距离表达段落间隔；这个可见边界映射完整源码间隔，因此标准空白行不单独出现。
- 三个及以上连续行终止中，前面的额外行终止逐个保留为真实、可放置插入点、可选择和可删除的空行；最后两个行终止仍作为标准段落间隔合并。
- 删除或合并相邻块仍须通过既有编辑映射修改真实源码，不得重复同步或形成不可撤销状态。
- 源码模式始终原样显示全部换行；对照模式左侧原样显示，右侧采用本策略。
- fenced code block 内容、未知原样块内部的空行不折叠。
- 空行处理不得改变保存结果、撤销语义或 `DocumentSession` 唯一正文归属。

## 5. 初始范围边界

代码块和表格现有独立段前段后暂时保留；列表、引用沿用全局行距。本轮先由用户复核正文、标题和连续空行的实际观感，再决定是否把列表、引用、代码块和表格拆成独立参数。
