## 5. 8.3 验收记录

### 实现范围

- 新增 `DocumentCombineService::Prepare/Commit`、`InsertPlan` 和 `InsertResult`；来源只读加载为固定快照，来源文件不移动、不覆盖、不删除。
- `.md/.markdown/.txt` 复用既有 UTF-8 BOM、UTF-16 LE/BE BOM、严格 UTF-8 解码，静默转为会话内部 UTF-8；插入后不保留独立来源编码。
- 插入只补足前后边界所需的最少换行，并通过一次 `DocumentSession::commit` 提交，产生一个应用级事务和一个新修订。
- Markdown 普通相对链接按来源目录解析并以纯词法方式改写为相对当前文档的新路径；目标文件不必预先存在。跨盘符等无法安全改写的引用明确失败。
- Markdown 本地图片复制到当前 `<文档名>.assets`，使用不冲突名称并改写引用；远程图片、锚点和绝对 URI 原样保留。代码围栏和行内代码中的伪链接不改写。
- 当前文档未保存且来源 Markdown 含需改写的相对引用时拒绝执行。TXT 来源不扫描链接或图片。
- TXT 插入纯文本会话时保持原字符；TXT 插入 Markdown 会话时转义会触发 Markdown 语义的行首/行内标记，确保 `#` 等仍作为可见普通字符。
- 资源先复制、正文后提交；正文提交失败时只删除本事务新建资源。成功结果返回新建资源清单，供 UI 层将其登记到同一撤销项。
- 新增 4201～4207 稳定错误码并同步错误码表。
