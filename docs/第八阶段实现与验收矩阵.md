## 10. DEF-039 “最近文件”复发修复

- 用户现场：从 Release 的“文件 → 最近文件”打开约 49 KB 原文件后卡死；标题已更新为目标文件，进程 CPU 持续增长。

- 修复：最近文件快照由专用 `WM_APP` 消息合并延迟到菜单命令返回后应用；删除失败立即退出，杜绝无界循环。
- 真实复测：正式 Release EXE 使用用户原文件执行相同菜单路径，标题更新后 `tasklist` 两次间隔采样 CPU 时间保持稳定，窗口消息状态恢复；仍等待用户亲自复测确认。
