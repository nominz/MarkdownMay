## 3. 8.1 验收记录

### 实现范围

- `DocumentSession` 新增 `DocumentKind { markdown, plain_text }`，构造默认仍为 Markdown，既有调用兼容。
- `SessionSnapshot` 固定携带文档类型；纯文本会话保留唯一 UTF-8 源码、修订、脏状态和事务，但不解析或伪造 Markdown 语义树。
- 纯文本会话禁用语义提交、后台 Markdown 解析结果接收和 `can_export()`，为 8.4 UI 能力门禁提供稳定底层契约。
- 新增 `SourcePositionMapper::MapCaret`，统一验证表面/会话修订一致、折叠插入点、源码范围、UTF-8 码点边界和 CRLF 边界。
- 既有 RichEdit `ProjectionMap`、Scintilla UTF-8 选区和对照左栏仍负责原生位置到源偏移换算；后续切分/插入只使用本公共门禁，不建立三套业务映射。
