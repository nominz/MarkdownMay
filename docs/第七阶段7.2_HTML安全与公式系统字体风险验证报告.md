# 第七阶段 7.2 HTML 安全与公式系统字体风险验证报告

> 日期：2026-08-12
>
> 上位基线：`需求规格说明书_V04.md` 1.0
>
> 性质：风险样机；不是正式 HTML writer 或用户可见导出功能

## 1. 验证目标

1. 单个 HTML 文件能否在不引用伴随目录、CDN、外部脚本和外部字体的条件下安全打开；
2. 不可信正文、Mermaid 和公式源码能否完整保留而不成为活动内容；
3. 浏览器原生 MathML 是否能只使用 Windows 已安装字体完成可接受的基础公式排版；
4. Mermaid 在不引入 WebEngine、外部进程、网络或运行时下载时还缺少哪些正式实现条件。

## 2. 样机范围

`prototype/core/safe_html_probe.*` 生成单文件 HTML，包含：

- UTF-8 文档和内嵌 CSS；
- `default-src 'none'`，并显式设置 `script-src 'none'`、`connect-src 'none'`、`font-src 'none'`、`object-src 'none'`、`base-uri 'none'`、`form-action 'none'`；
- 带 `<img onerror>` 和 `<script>` 的攻击字符串；
- Mermaid 源码可见回退容器；
- 二次方程求根公式的原生 MathML 和原始 LaTeX 源码折叠区；
- 不包含 JavaScript、外部 URL 属性、图片、字体或伴随资源。

`tests/html_export_probe.cpp` 验证输出结构、CSP、转义、外部资源属性、Mermaid 回退和 MathML 命名空间。样机生成文件为 2049 字节。

## 3. 自动与浏览器证据

### 3.1 结构测试

- `html_export_probe` 通过；
- 攻击标签以 `&lt;...&gt;` 形式保留；输出不存在活动 `<script>` 或攻击 `<img>`；
- 不存在 `src="http..."`、`href="http..."` 或 CSS `url(http...)`；
- CSP 同时禁止默认加载、脚本、连接、字体、对象、base 和表单提交。

### 3.2 本地浏览器测试

浏览器安全策略不允许自动化直接导航 `file://`。按本地网页测试规范，使用仅绑定 `127.0.0.1` 的临时只读 HTTP 服务打开同一构建产物；测试完成后服务进程已停止。该服务不对局域网或互联网监听。

实际 DOM/渲染结果：

| 检查项 | 结果 |
| --- | --- |
| 文档加载 | `readyState=complete` |
| 攻击脚本执行标记 | 不存在 |
| `<script>` 节点 | 0 |
| `<img>` 节点 | 0 |
| `src`/`href` 资源属性 | 0 |
| 不可信攻击原文 | 作为可见文字保留 |
| Mermaid | `source-fallback`，源码可见 |
| MathML 命名空间 | `http://www.w3.org/1998/Math/MathML` |
| MathML 实际布局 | 块级，约 798 × 52.22 px |
| 计算字体回退链 | `Cambria Math`, `Segoe UI Symbol`, serif |
| 浏览器警告/错误日志 | 0 |

人工查看截图确认分数线、根号、上标和正负号完成了二维数学排版，不是普通线性文本。

## 4. 风险结论

### 4.1 已通过的路线

- 安全语义 HTML、完整转义、严格 CSP 和单文件内嵌 CSS 可行；
- 原生 MathML 能在当前 Windows 浏览器中使用系统 `Cambria Math` 完成基础公式排版，不需要携带字体；
- 公式必须同时保留原始源码和可见失败回退；后续还需覆盖更多公式、浏览器版本、字体缺失和打印预览，当前不能宣称完整 LaTeX 兼容。

### 4.2 Mermaid 门禁

浏览器没有原生 Mermaid 解析/布局能力。要满足 V04 HTML-004，正式实现必须选择固定版本的 Mermaid 渲染资源，并完成：

1. 许可证和 NOTICE 要求审查；
2. 已知漏洞、危险配置、外链和回调能力审查；
3. 禁止网络、动态模块加载和任意脚本入口；
4. 资源作为数据静态编入单 EXE，只写入用户明确导出的单个 HTML；
5. 验证严格 CSP 下的执行方式、失败超时、资源上限和源码回退；
6. 记录 Release EXE 与导出 HTML 的体积增量。

仓库当前没有已经批准的 Mermaid 资源。7.2 不联网下载、不提交未经审查的第三方脚本。因此当前正式结论是“源码回退安全可用，浏览器绘图仍受依赖审查门禁”，不得把样机写成 Mermaid 已完成。

## 5. 对后续增量的约束

- 7.3 公共任务管线必须支持 HTML 资源预算、取消、失败清理和原子替换；
- 7.7 `SafeHtmlWriter` 复用本样机的转义和 CSP 不变量，但不得直接复制样机拼接代码作为完整 writer；
- MathML 生成器必须是受限公式语法到安全 MathML 的转换，不允许把用户提供的任意 MathML/HTML 原样注入；
- Mermaid 依赖评审未完成时，7.7 必须保留源码回退，不得假装绘图成功；
- 真实 `file://` 双击打开、更多浏览器、打印预览、字体缺失和复杂公式进入 7.7/7.8 兼容性矩阵。
